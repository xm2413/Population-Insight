# 人口趋势与分析管理系统项目说明书

## 一、项目背景

本项目面向人口数据管理与趋势分析场景，使用 Python、Flask、SQLite 和 Matplotlib 实现人口数据的录入、查询、修改、删除、统计分析、可视化展示、趋势预测、风险预警和导入导出等功能。

## 二、功能模块

系统当前包含 11 个主要功能模块，满足“不少于 8 个独立功能模块”的要求：

1. 登录与权限控制：管理员可维护数据，查看者只能查看分析结果。
2. 人口数据新增：录入地区年度人口指标。
3. 人口数据查询：按地区、年份、关键词筛选。
4. 人口数据修改：管理员可编辑已有记录。
5. 人口数据删除：管理员可删除错误记录。
6. 统计分析：计算地区人口变化、变化率、老龄化率、城镇化率等。
7. 全球人口统计：按国家和洲维度统计全球人口样本数据。
8. 地区对比：选择多个地区进行同年份横向对比。
9. 趋势预测：基于历史数据进行简单线性回归预测。
10. 数据可视化：使用 Matplotlib 生成折线图、柱状图、饼图。
11. 数据导入导出与日志：支持 CSV 批量导入、CSV 导出和操作日志记录。

## 三、技术方案

- 开发语言：Python
- Web 框架：Flask
- 数据库：SQLite
- 可视化：Matplotlib
- 前端：HTML、CSS、服务端模板渲染
- 数据持久化：所有人口数据、用户、地区档案、操作日志均存储在 SQLite 数据库中

## 四、数据库设计

### users 用户表

保存系统用户、密码哈希和角色信息。

### population_records 人口数据表

保存地区、年份、总人口、男性人口、女性人口、出生率、死亡率、自然增长率、老龄化率、城镇化率、数据来源和备注。

### global_population_records 全球人口数据表

保存国家、所属洲、年份、总人口、男性人口、女性人口、出生率、死亡率、自然增长率、老龄化率、城镇化率、数据来源和备注，用于全球人口统计页面。

### regions 地区档案表

保存地区名称、地区类型、行政编码和说明。

### operation_logs 操作日志表

记录登录、导入、导出、新增、编辑、删除等关键操作。

## 五、模块化设计

- `app.py`：Web 路由与页面组织
- `population_trend/config.py`：配置、指标名称、样例数据
- `population_trend/database.py`：数据库连接、建表、初始化
- `population_trend/auth.py`：登录认证、权限校验、操作日志
- `population_trend/record_service.py`：人口数据增删改查、导入导出、地区维护
- `population_trend/analysis_service.py`：统计分析、全球人口统计、趋势预测、风险预警
- `population_trend/visualization_service.py`：Matplotlib 图表生成
- `population_trend/validators.py`：输入数据校验函数

## 六、可视化设计

系统提供 Matplotlib 生成的多类图表：

- 折线图：展示总体人口随年份变化趋势
- 柱状图：展示最新年份地区人口排名
- 饼图：展示最新年份性别结构比例
- 全球折线图：展示国家样本合计人口变化趋势

图表文件输出到 `static/charts/`，在系统“可视化”页面中展示。
